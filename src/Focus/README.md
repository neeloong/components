聚焦 `<nl-focus>`
------------------------


### 属性

| HTML属性    | JS 属性     | css 属性 | 类型     | 说明           |
| ----------- | ----------- | -------- | -------- | -------------- |
| `target` | `target` |          | `string` | 聚焦位置(目标元素选择器) |
|   | `targetElement` |          | `Element?` | 聚焦位置(目标元素) |
| `x` | `x` |          | `number` | 聚焦位置(X) |
| `y` | `y` |          | `number` | 聚焦位置(Y) |
| `width` | `width` |          | `number` | 聚焦位置(宽度) |
| `height` | `height` |          | `number` | 聚焦位置(高度) |
|          |          | `color`  | `color` | 遮罩颜色 |
